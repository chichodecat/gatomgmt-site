# gatomgmt.com

Website of Gato MGMT (Chicho Decat). Plain HTML, hosted on GitHub Pages.

- `index.html` home page (split musician / manager)
- `music.html` musician page (records + videos)
- `manager.html` management projects
- `impressum.html`, `privacy.html` legal pages
- `img/` photos, `brand/` logo files, `fonts/` self-hosted fonts

Every push to `main` goes live automatically.
